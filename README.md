## 🌐 How to Host Online (Free & Fast)

### Option 1: GitHub Pages
1. Create a free account on [GitHub.com](https://github.com).
2. Create a new repository (e.g. `ankita-portfolio`).
3. Upload all files (`index.html`, `style.css`, `script.js`, `resume.html`).
4. Go to **Settings > Pages > Branch: main > Save**.
5. Your portfolio will be live at `https://<your-username>.github.io/ankita-portfolio/`!

### Option 2: Netlify Drop
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `Digital literacy` folder.
3. Your portfolio gets deployed instantly with a free URL!
